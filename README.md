# Employee Attrition Analysis

## Overview

This project analyzes employee attrition using HR analytics and machine learning.

The goal is to understand factors that influence employee turnover and predict whether an employee is likely to leave.

## Objectives

- Analyze employee attrition patterns
- Study age, salary and department
- Perform exploratory data analysis
- Build a classification model
- Predict employee attrition
- Create HR KPIs and visualizations

## Dataset

The dataset contains **1,470 employee records** with information such as:

- Age
- Department
- Monthly Income
- Job Satisfaction
- OverTime
- Education
- Job Role
- Attrition

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest
- VS Code

## Methodology

1. Load the HR dataset
2. Check missing values and duplicates
3. Perform exploratory data analysis
4. Analyze age, salary and department
5. Convert categorical data into numerical values
6. Split the data into training and testing sets
7. Train a Random Forest classification model
8. Evaluate the model
9. Identify important factors
10. Create HR KPI visualizations

## Machine Learning

A **Random Forest Classifier** was used to predict employee attrition.

### Model Accuracy

The model achieved **87.76% accuracy** on the test dataset.

## Key Results

- Total Employees: **1,470**
- Employees Who Left: **237**
- Attrition Rate: **16.12%**
- Model: **Random Forest Classifier**
- Accuracy: **87.76%**

## Conclusion

This project demonstrates how HR analytics and machine learning can be used to understand employee attrition. The analysis can help organizations identify factors related to employee turnover and support better employee retention strategies.
